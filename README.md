# La Bannière disparue — PWA V4

Jeu de piste familial sur Jeanne d’Arc à Orléans, conçu pour une enfant de 7 ans.

## Déploiement GitHub Pages

1. Copiez **le contenu de ce dossier** à la racine de votre dépôt GitHub.
2. Vérifiez que `index.html`, `app.js`, `styles.css`, `sw.js` et `manifest.webmanifest` sont directement à la racine.
3. Dans GitHub : **Settings → Pages → Deploy from a branch → main / root**.
4. Attendez la fin du workflow dans l’onglet **Actions**, puis ouvrez l’adresse indiquée dans Settings → Pages.

## Contenu V4

- 8 étapes liées aux lieux visités ;
- 2 jeux maximum par lieu ;
- transitions avec nom, adresse, temps de marche et indice ;
- mode express à une épreuve ;
- fonctionnement hors ligne après le premier chargement ;
- progression sauvegardée localement ;
- diplôme final imprimable ;
- aucun compte ni serveur requis.

## Mise à jour depuis une ancienne version

Remplacez tous les anciens fichiers. Si le téléphone affiche encore une ancienne version, supprimez l’application de l’écran d’accueil, videz les données du site dans Safari, puis ouvrez de nouveau l’adresse GitHub Pages.
